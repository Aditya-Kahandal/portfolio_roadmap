### Today's DSA problem explaination:
The task finding the smallest possible gap between two similar alert_ids inside an array. To perform that the basic idea was to go with the idea of current index of the element, this makes sure that the previously seen element from the dictionary(hash_map) is the closest.

TIME COMPLEXITY: O(n)
SPACE COMPLEXITY: O(U), where U is the number of unique alert-ids in the array.

My engineering mistakes were that :
I applied the constraint value to the solutions initialization step(which was 100,000), instead of using float("inf") which give largest floating point value so that the solution is applicable to any possible constraint in future.
The second mistake was not naming the function correctly.
